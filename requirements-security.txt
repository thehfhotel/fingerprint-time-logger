# INSTALLATION NOTES
# ============================================================================
#
# To install security testing dependencies:
#   pip install -r requirements.txt -r requirements-security.txt
#
# For development with security testing:
#   pip install -r requirements.txt -r requirements-security.txt -r requirements-dev.txt
#
# For minimal security testing (CI/CD):
#   pip install bandit safety pytest-security pytest-timeout
#
# Note: Some advanced tools (commented out) require additional system dependencies
#       and may significantly increase installation time and size.
#
# Version pinning strategy:
#   - Core security tools: Pinned to specific versions for consistency
#   - Utility libraries: Compatible versions with main requirements
#   - Optional tools: Latest stable versions
#
# Security considerations:
#   - All dependencies regularly audited with safety and pip-audit
#   - Versions selected to avoid known vulnerabilities
#   - Minimal necessary dependencies to reduce attack surface
